# Proyecto

Aquí se incorporará la aplicación cuando se confirme el entorno y la tecnología de interfaz.

## Organización prevista

- `src/`: código fuente.
- `database/`: scripts y archivos de estructura de la base de datos.
- `resources/`: imágenes y otros recursos de la interfaz.

No subir contraseñas, archivos temporales del IDE ni datos personales o clínicos reales.
