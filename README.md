# ProjectMed

Repositorio de trabajo y seguimiento académico del sistema de reservas y atención para un centro de salud.

## Objetivo

Desarrollar progresivamente el proyecto, manteniendo alineados el análisis, el modelado, la implementación y la documentación. Cada cambio importante debe quedar registrado en Git.

## Organización

- `01_PROYECTO/`: código fuente, recursos y base de datos.
- `02_MODELADO/`: procesos, casos de uso, clases, datos y arquitectura.
- `03_DOCUMENTACION/`: informe, especificaciones, manuales y evidencias.
- `04_TAREAS/`: actividades asignadas y entregas.
- `05_SEGUIMIENTO/`: avances, observaciones y decisiones técnicas.
- `06_RECURSOS/`: referencias y materiales de apoyo.

## Forma de trabajo

1. Revisar la tarea antes de comenzar.
2. Realizar cambios pequeños y relacionados con una tarea.
3. Guardar avances mediante commits con mensajes descriptivos.
4. Actualizar la documentación cuando cambien los procesos o decisiones.
5. No incorporar datos reales ni información identificable de pacientes.

## Estado inicial

El repositorio se utiliza para organizar y supervisar el desarrollo. Las tecnologías y la estructura definitiva de la aplicación se confirmarán durante la primera tarea.
