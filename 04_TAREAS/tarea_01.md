# Tarea 01 — Preparar y delimitar el proyecto

## Objetivo

Dejar establecido el punto de partida técnico y organizativo antes de comenzar a implementar funcionalidades.

## Actividades

1. Revisar el proyecto y los diagramas existentes.
2. Identificar qué funcionalidades forman parte del alcance actual.
3. Confirmar el entorno de desarrollo utilizado y cómo está construida la interfaz actual (por ejemplo, formularios Swing de NetBeans, si corresponde).
4. Identificar qué motor de base de datos se utilizará y cómo se conectará desde la aplicación.
5. Proponer una estructura inicial de paquetes y explicar la responsabilidad de cada uno.
6. Registrar las dudas, decisiones pendientes y posibles inconsistencias detectadas en el modelado.

## Entregables

- Nota breve con el entorno de desarrollo y las tecnologías confirmadas.
- Estructura inicial de carpetas o paquetes, todavía sin implementar funcionalidades.
- Lista de decisiones pendientes y preguntas que requieren revisión.

## Criterios de revisión

- Las decisiones se justifican y no se presentan como hechos si aún no se han confirmado.
- La estructura propuesta es comprensible y adecuada al nivel actual del proyecto.
- Se distinguen las funcionalidades definidas de las que todavía necesitan especificación.
- Los avances se registran en Git mediante commits descriptivos.

## Evidencia

Subir los archivos de trabajo y dejar en el historial los commits correspondientes.
